# 🎥 GestureFlow

> Hand Gesture Controlled Presentation & Air Canvas using Python, OpenCV & MediaPipe.

---

## 📖 Project Overview

GestureFlow is a Computer Vision based desktop application that allows users to control presentations and draw in the air using only hand gestures captured through a webcam.

The project aims to provide an affordable touchless presentation solution without requiring expensive smart boards or presentation remotes.

---

## ✨ Planned Features

### Phase 1 (MVP)

- Webcam Integration
- Hand Detection
- Finger Tracking
- Air Canvas
- Color Selection
- Clear Canvas
- Save Drawing
- Next Slide Gesture
- Previous Slide Gesture

### Phase 2

- Undo / Redo
- Brush Size Control
- Laser Pointer
- Gesture Customization

### Future Scope

- OCR
- AI Handwriting Recognition
- PDF Annotation
- Voice Commands
